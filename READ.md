EyeCare AI – Early Detection of Eye Diseases

Project Overview

EyeCare AI is an interpretable machine learning framework designed to assist in the early detection of eye diseases using retinal images. The system uses deep learning techniques to classify eye conditions and provides visual explanations using Grad-CAM.

Objectives

- Develop an AI-based eye disease classification system.
- Apply deep learning for image analysis.
- Improve model interpretability using Grad-CAM.
- Provide an easy-to-use web interface for image-based predictions.

Technologies Used

- Programming Language: Python
- Deep Learning: PyTorch, CNN, EfficientNet
- Explainable AI: Grad-CAM
- Backend: Flask
- Frontend: HTML, CSS, JavaScript
- Database: As implemented in the project

Key Features

- Eye image upload and classification.
- Prediction results with confidence scores.
- Grad-CAM visual explanations.
- User authentication.
- Prediction history.

Project Structure

- "app.py" – Main Flask application
- "database.py" – Database operations
- "models/" – Trained model files
- "src/" – Source code
- "templates/" – HTML templates
- "requirements.txt" – Project dependencies

Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/vijaykrishnak95-hue/eyecare-ai.git

2. Open the project directory:
   
   cd eyecare-ai

3. Create a virtual environment:
   
   python -m venv venv

4. Activate the environment (Windows):
   
   venv\Scripts\activate

5. Install dependencies:
   
   pip install -r requirements.txt

6. Run the application:
   
   python app.py
