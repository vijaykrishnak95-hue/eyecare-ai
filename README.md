# EyeCare AI – Early Detection of Eye Diseases

## Project Overview
EyeCare AI is an interpretable machine learning framework designed to assist in the early detection of eye diseases using retinal images. It uses deep learning and Explainable AI techniques to provide predictions and visual explanations.

## Objectives
- Develop an AI-based eye disease detection system.
- Classify eye images using deep learning.
- Improve model interpretability using Grad-CAM.
- Provide a user-friendly web application.

## Technologies Used
- Python
- PyTorch
- CNN
- EfficientNet
- Grad-CAM
- Flask
- HTML
- CSS
- JavaScript
- Database (as implemented)

## Key Features
- User registration and login.
- Eye image upload.
- Disease classification and confidence scores.
- Grad-CAM visual explanations.
- Prediction history.

## Project Structure
- app.py – Main Flask application.
- database.py – Database operations.
- models/ – Trained model files.
- src/ – Source code.
- templates/ – HTML templates.
- requirements.txt – Dependencies.

## Installation

1. Clone the repository:

   git clone https://github.com/vijaykrishnak95-hue/eyecare-ai.git

2. Open the project folder:

   cd eyecare-ai

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python app.py
