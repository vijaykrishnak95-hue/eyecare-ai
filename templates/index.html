About the Project

This academic research project uses an EfficientNet deep learning model to classify retinal images into supported categories. Grad-CAM heatmaps help visualize image regions that influence the model's prediction.

Deep Learning

Explore retinal image classification using an EfficientNet model.

Explainable AI

Visualize model attention using Grad-CAM heatmaps and overlays.

Four Categories

Cataract, diabetic retinopathy, glaucoma and normal, when supported by the dataset.

Eye Disease Information

Cataract

Clouding of the eye's natural lens that can affect vision.

Diabetic Retinopathy

Damage to retinal blood vessels associated with diabetes.

Glaucoma

A group of eye conditions that can damage the optic nerve.

Normal

A dataset category for images labelled as normal or healthy.
